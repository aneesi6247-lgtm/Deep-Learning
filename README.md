# Deep Learning

A collection of deep learning notebooks covering neural network fundamentals through CNNs and RNNs, built while studying deep learning theory and practice.

## Contents

| Notebook | Topic |
|---|---|
| `Neuron_part_01.ipynb` | Single neuron / perceptron fundamentals |
| `ANN_part_03.ipynb` | Artificial Neural Networks (ANN) |
| `Part_03ANN_CLASSIFICAITON.ipynb` | ANN applied to classification |
| `Part_05_CNNs.ipynb` | Convolutional Neural Networks |
| `Part_06_RNN.ipynb` | Recurrent Neural Networks |
| `Assignment_project_with_CNN.ipynb` | CNN applied to an image classification task (MNIST) |
| `Assignment_project_with_RNN.ipynb` | RNN applied to a sequence task (IMDB sentiment) |

## Datasets used

- **MNIST** — handwritten digit classification (`Assig_data/MNIST/raw`)
- **IMDB Dataset** — movie review sentiment classification
- **Date Fruit Dataset** — tabular classification
- **Power Plant Data** — regression on power output

## Stack

PyTorch · Jupyter Notebook · Python

## Notes

This repo documents the progression from neuron-level fundamentals to full architectures (CNN, RNN), with each notebook building on concepts from the previous one. `best_model.pt` is a saved model checkpoint from one of the assignment notebooks.
